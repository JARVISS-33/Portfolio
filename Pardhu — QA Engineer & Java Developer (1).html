I’m Battepati Venkat Pardhu, a QA engineer from Nellore, Andhra Pradesh. I work in automation testing and manual testing, and I also build applications in Java. That mix means I don’t only report what is broken. I understand why it breaks and how it should be fixed.

I use SQL and JDBC to confirm that what a screen shows matches what the database stores, and AWS for cloud test environments. I use AI tools like Claude to draft test cases, test data and bug summaries faster. I read and verify every output, and I never share confidential data with them.

My own projects, SCScan, Skill Interview Studio and Residency, are applications I designed, built and tested myself.

Quality engineering

I turn requirements into test cases, then run functional, exploratory, smoke, sanity and regression testing, by hand and with automation, across more than 100 applications.

Defects are reported from first sight to closure with clear steps, evidence, severity and priority, and I retest every fix before calling it done.

Software development

I develop applications in Java and connect them to databases with SQL and JDBC, reading, adding, updating and verifying data the way a real product does.

Because I build as well as test, I think about edge cases, data integrity and security while writing the code, not after it ships.
